## 新建数据集

**接口地址**:`/api/v1/fileExplorer/feDatasets`

**请求方式**:`POST`

**请求数据类型**:`application/json`



**请求示例**:


```javascript
{
  "dataType": 0,
  "name": "数据集123",
  "remark": "这是描述123",
  "type": 0
}
```


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|dataType|数据类型||true|integer(int64)||
|name|数据集名称||true|string||
|remark|数据集描述||true|string||
|type|是否公开：0-私有，1-公开||true|integer(int32)||
|Authorization|令牌|header|false|string||



**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- |
|code|返回状态码|integer(int32)|integer(int32)|
|data|泛型数据|FeDatasetVO|FeDatasetVO|
|&emsp;&emsp;createBy|创建人名字|string||
|&emsp;&emsp;createTime|创建时间|string(date-time)||
|&emsp;&emsp;createUserId|创建人id|integer(int64)||
|&emsp;&emsp;dataType|数据类型id|integer(int64)||
|&emsp;&emsp;id|数据集id|integer(int64)||
|&emsp;&emsp;name|数据集名称|string||
|&emsp;&emsp;path|数据集路径|string||
|&emsp;&emsp;remark|数据集描述信息|string||
|&emsp;&emsp;type|类型 0: private 私有数据, 1:public 公开数据|integer(int32)||
|&emsp;&emsp;uploadPrefix|上传文件前缀|string||
|msg|返回信息|string||
|traceId|链路追踪ID|string||


**响应示例**:
```javascript
{
	"code": 0,
	"data": {
		"createBy": "",
		"createTime": "",
		"createUserId": 0,
		"dataType": 0,
		"id": 0,
		"name": "",
		"path": "fe-dataset/235",
		"remark": "",
		"type": 0,
		"uploadPrefix": "fe-dataset/235/1"
	},
	"msg": "",
	"traceId": ""
}
```


## 生成数据集文件上传临时地址

**接口地址**:`/api/v1/fileExplorer/feDatasets/getUploadUrl`


**请求方式**:`POST`

**请求数据类型**:`application/json`



**请求示例**:


```javascript
{
  "fileObjects": ["test/tt.py","val/11.txt"],
  "uploadPrefix": "fe-dataset/235/1"
}
```


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|fileObjects|文件列表||false|array|string|
|uploadPrefix|文件前缀||false|string||
|Authorization|令牌|header|false|string||



**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- |
|code|返回状态码|integer(int32)|integer(int32)|
|data|泛型数据|object||
|msg|返回信息|string||
|traceId|链路追踪ID|string||
